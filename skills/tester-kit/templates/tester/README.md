# 测试工程师模板

## 当前可用模板

- `test-plan-template.md`：用于输出测试计划、测试场景、测试用例、回归范围和发布验收建议。
- `acceptance-criteria-review-template.md`：用于检查验收标准是否可测试、可判断、可追踪。
- `test-strategy-planning-template.md`：用于输出测试策略、测试层级、风险优先级和准入准出。
- `test-scope-analysis-template.md`：用于整理测试范围、非范围、验收标准和风险。
- `test-data-environment-template.md`：用于整理测试环境、账号权限、测试数据和依赖。
- `test-case-template.md`：用于输出可执行测试用例。
- `api-integration-test-template.md`：用于整理接口契约、数据流、错误码和集成测试场景。
- `compatibility-test-template.md`：用于输出兼容性测试矩阵。
- `non-functional-risk-test-template.md`：用于整理性能、稳定性、安全和数据一致性等非功能风险。
- `regression-test-template.md`：用于输出回归测试范围。
- `exploratory-test-template.md`：用于记录探索式测试目标、发现和补充用例。
- `automation-test-planning-template.md`：用于规划自动化测试候选场景、分层和维护成本。
- `defect-reproduction-template.md`：用于输出缺陷复现报告。
- `test-execution-report-template.md`：用于输出测试执行结果、缺陷统计、风险和发布建议。
- `release-acceptance-template.md`：用于输出发布验收结论。
