# 测试数据与环境准备工作流

## 目的

用于明确测试执行所需的环境、账号、权限、数据状态、配置和外部依赖。

## 什么时候使用

- 测试用例已经有了，但缺少数据和环境准备。
- 功能依赖账号角色、配置开关、第三方服务、支付、消息、上传或异步任务。
- 回归或发布前需要确认环境是否可测。

## 执行步骤

1. 列出测试环境、版本、配置和依赖服务。
2. 列出账号、角色、权限和数据状态。
3. 标记需要造数、清理、隔离或重置的数据。
4. 标记外部依赖和不可控风险。
5. 输出测试准备清单。

## 输出要求

- 环境清单。
- 账号和权限清单。
- 测试数据清单。
- 配置和依赖清单。
- 阻塞项和替代方案。
