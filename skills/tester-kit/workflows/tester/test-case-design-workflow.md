# 测试用例设计工作流

## 目的

基于测试范围、PRD、验收标准和开发变更，设计可执行的测试场景和测试用例。

## 适用场景

- 已完成测试范围分析。
- 已有 PRD 和验收标准。
- 需要产出功能测试、边界测试、异常测试和权限测试用例。

## 执行步骤

1. 提取核心用户路径。
2. 拆分测试场景。
3. 为每个场景设计用例。
4. 补充边界、异常、权限、数据状态和兼容场景。
5. 标记优先级。
6. 输出测试用例和待确认问题。

## 输出

使用：

```text
06-templates/tester/test-case-template.md
```

## 质量检查

使用：

```text
11-evaluations/output-scorecards/test-case-scorecard.md
```
