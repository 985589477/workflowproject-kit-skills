# 兼容性测试工作流

## 目的

用于规划 Web、移动端、桌面端、多浏览器、多系统、多设备和特殊屏幕形态的兼容测试范围。

## 什么时候使用

- 功能面向多端、多浏览器或多设备。
- UI、交互、上传、媒体、支付、地图、扫码、相机等能力依赖设备环境。
- 需要覆盖 iPad、横屏、折叠屏、分屏、双屏或不同屏幕尺寸。

## 执行步骤

1. 确认目标平台、设备、系统、浏览器和分辨率。
2. 按用户占比、业务风险和实现差异确定测试矩阵。
3. 标记必须覆盖、抽样覆盖和可暂缓覆盖项。
4. 设计核心路径兼容用例。
5. 输出兼容性测试矩阵和风险说明。

## 输出要求

- 兼容范围。
- 设备和环境矩阵。
- 核心路径测试项。
- 特殊设备测试项。
- 不覆盖项和风险。
