# 接口与集成测试工作流

## 目的

用于检查接口契约、前后端集成、模块协作和外部服务依赖是否符合预期。

## 什么时候使用

- 功能依赖接口、数据同步、异步任务或第三方服务。
- 前后端联调前后需要测试方案。
- 缺陷可能来自模块边界或接口契约不一致。

## 执行步骤

1. 梳理接口、数据流、调用链和依赖模块。
2. 检查请求参数、响应字段、错误码、权限和幂等规则。
3. 设计正常、异常、边界、超时、重试和并发场景。
4. 标记前端、后端、第三方各自的责任边界。
5. 输出接口与集成测试清单。

## 输出要求

- 接口范围。
- 数据流和依赖。
- 接口用例。
- 错误码和异常场景。
- 联调风险和责任边界。
