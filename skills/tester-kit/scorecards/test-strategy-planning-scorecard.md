# 测试策略规划评分表

适用对象：测试策略、测试计划前置规划

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 目标清晰 | 20 | 是否明确测试目标、范围和约束 |
| 层级完整 | 20 | 是否覆盖单元、接口、集成、端到端、兼容和非功能层级 |
| 风险驱动 | 25 | 是否按业务影响和技术风险确定优先级 |
| 取舍明确 | 20 | 是否说明必测、抽测、暂缓和不测内容 |
| 准入准出 | 15 | 是否定义测试开始和结束条件 |

## 结论

90-100 可作为测试策略执行；75-89 可试用；60-74 需补风险和取舍；0-59 需要重做。
