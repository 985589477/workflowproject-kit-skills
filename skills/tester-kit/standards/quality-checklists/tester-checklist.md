# 测试质量检查清单

## 适用对象

- 测试计划
- 测试策略
- 验收标准检查
- 测试数据与环境准备
- 测试用例
- 接口与集成测试
- 兼容性测试
- 非功能风险测试
- 回归测试范围
- 缺陷复现说明
- 探索式测试记录
- 自动化测试规划
- 测试执行报告
- 发布验收结论

## 检查项

| 类别 | 检查项 | 是否通过 | 说明 |
| --- | --- | --- | --- |
| 范围 | 是否明确测试范围和非范围 |  |  |
| 输入 | 是否承接 PRD、验收标准或开发变更 |  |  |
| 验收标准 | 是否检查验收标准可测试、可判断、可追踪 |  |  |
| 策略 | 是否说明测试层级、风险优先级、准入准出和测试取舍 |  |  |
| 环境 | 是否说明测试环境、账号、权限、数据和外部依赖 |  |  |
| 场景 | 是否覆盖核心用户路径 |  |  |
| 边界 | 是否覆盖边界、异常、空态和错误场景 |  |  |
| 权限 | 是否覆盖登录、权限、角色或数据差异 |  |  |
| 数据 | 是否说明测试数据和前置条件 |  |  |
| 接口集成 | 是否覆盖接口契约、数据流、错误码、超时、重试和幂等 |  |  |
| 兼容 | 是否覆盖目标设备、系统、浏览器和特殊屏幕形态 |  |  |
| 非功能 | 是否识别性能、稳定性、安全、数据一致性、可用性和监控风险 |  |  |
| 回归 | 是否明确回归范围 |  |  |
| 探索 | 是否记录常规用例外的探索发现和补充用例 |  |  |
| 自动化 | 是否判断自动化价值、分层、成本和维护风险 |  |  |
| 风险 | 是否标记高风险模块和发布风险 |  |  |
| 用例 | 是否具备步骤、预期结果和优先级 |  |  |
| 报告 | 是否汇总执行结果、缺陷状态、阻塞项和未覆盖范围 |  |  |
| 结论 | 是否给出可执行的验收建议 |  |  |

## 结论

```text
可执行 / 补充后执行 / 暂不执行 / 需要用户确认
```
