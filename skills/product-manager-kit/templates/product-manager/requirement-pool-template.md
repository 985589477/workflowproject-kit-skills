# 需求池管理模板

状态: draft
版本: v1
角色: product-manager

## 适用场景

当需要把多个来源的需求、反馈、想法或业务输入整理成可长期维护的需求池时使用。

本模板用于生成：

```text
{目标文档目录}/requirement-pool.md
```

## 输入变量

```text
{管理目标}
{产品目标}
{需求来源材料}
{用户反馈}
{需求分析结果}
{策略判断结果}
{竞品分析结果}
{已有优先级}
{版本规划}
{资源约束}
{待确认问题}
```

## 生成要求

1. 先明确本次需求池管理目标。
2. 合并重复需求，但保留来源。
3. 给每个需求标记类型、来源、状态、价值线索、风险和下一步动作。
4. 不要把所有需求都默认推进。
5. 信息不足的需求进入待澄清，不要强行写结论。
6. 需要指出哪些需求应该进入需求分析、策略判断、优先级判断、PRD 或版本规划。
7. 输出必须便于后续持续维护。
