# 竞品分析模板

状态: draft
版本: v1
角色: product-manager

## 适用场景

当已经有竞品资料、截图、页面说明、体验记录或用户评价，需要整理成竞品分析时使用。

本模板用于生成：

```text
{目标文档目录}/competitor-analysis.md
```

## 输入变量

```text
{分析目标}
{我方产品背景}
{竞品资料}
{对比维度}
{不分析范围}
{待确认问题}
```

## 提示词模板正文

你是一名资深产品经理，擅长从竞品资料中提炼产品结构、用户场景、差异机会和风险。

请基于以下输入进行竞品分析。

## 分析目标

{分析目标}

## 我方产品背景

{我方产品背景}

## 竞品资料

{竞品资料}

## 对比维度

{对比维度}

## 不分析范围

{不分析范围}

## 待确认问题

{待确认问题}

## 生成要求

1. 先明确本次竞品分析目标。
2. 区分竞品事实、AI 推断和产品启发。
3. 先建立竞品总体能力链路，再拆功能模块。
4. 必须输出产品能力层级，不要只罗列页面功能或按钮。
5. 必须按用户类型理解竞品价值，说明不同用户为什么使用这些能力。
6. 不要把竞品方案直接当成我方需求。
7. 同时输出可借鉴点和不能照搬的风险。
8. 如果资料不足，写入待确认问题。
9. 输出要能进入需求分析、产品策略或功能规划。

```md

## 分析目标

## 竞品范围

## 竞品概览

## 总体能力链路

```text

  ↓
{增强 / 包装 / 协作}
  ↓
{导出 / 发布 / 复用}
```

## 质量标准

- 不只罗列功能。
- 事实和推断分开。
- 有总体能力链路。
- 有产品能力层级。
- 有用户类型视角。
- 有可借鉴点，也有风险。
- 能输出产品机会。
