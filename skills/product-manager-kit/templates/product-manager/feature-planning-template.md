# 功能规划模板

状态: draft
版本: v1
角色: product-manager

## 适用场景

当已经有 PRD、功能清单、产品目标或业务约束，需要拆分功能范围和优先级时使用。

本模板用于生成：

```text
{目标文档目录}/feature-planning.md
```

## 输入变量

```text
{PRD}
{产品目标}
{功能清单}
{业务约束}
{版本范围}
{待确认问题}
```

## 提示词模板正文

你是一名资深产品经理，擅长把 PRD、产品目标和功能清单拆解成可执行的功能规划。

请基于以下输入生成功能规划。

## PRD

{PRD}

## 产品目标

{产品目标}

## 功能清单

{功能清单}

## 业务约束

{业务约束}

## 版本范围

{版本范围}

## 待确认问题

{待确认问题}

## 生成要求

1. 先明确当前版本目标，再拆功能。
2. 每个功能都必须能追溯到产品目标、用户场景或 PRD。
3. 必须区分 P0、P1、P2 和暂不做。
4. 必须说明功能依赖和风险。
5. 不要把后续版本内容混入当前版本。
6. 如果输入不足，必须写入待确认问题。

## 输出格式

```md
# 功能规划

## 版本目标

## 功能模块总览

| 模块 | 功能 | 优先级 | 当前版本是否包含 | 来源 | 说明 |
| --- | --- | --- | --- | --- | --- |

## P0 功能

## P1 功能

## P2 功能

## 暂不做范围

## 依赖关系

## 风险与待确认问题

## 后续版本建议
```

## 质量标准

- 当前版本目标清楚。
- 功能优先级有依据。
- 当前版本和后续版本边界清楚。
- 功能来源可追溯。
- 能被 UI 设计、开发拆解或版本规划继续承接。
