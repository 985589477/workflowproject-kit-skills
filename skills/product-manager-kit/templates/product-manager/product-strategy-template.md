# 产品策略判断模板

状态: draft
版本: v1
角色: product-manager

## 适用场景

当需要判断一个产品方向、机会点、策略主题或功能方向是否值得推进时使用。

本模板用于生成：

```text
{目标文档目录}/product-strategy.md
```

## 输入变量

```text
{判断对象}
{产品目标}
{用户问题}
{目标用户}
{核心场景}
{业务目标}
{竞品和市场信号}
{资源约束}
{风险和假设}
{待确认问题}
```

## 提示词模板正文

请基于以下输入输出产品策略判断。

## 生成要求

1. 先明确本次策略判断对象。
2. 区分用户问题、业务目标、市场机会和资源约束。
3. 判断方向是否成立，不能只写“建议推进”。
4. 必须说明推进、暂缓或不推进的理由。
5. 必须写清目标用户、核心场景和核心价值。
6. 必须保留风险、假设和待确认问题。
7. 必须给出后续应该进入哪个产品工作流。
