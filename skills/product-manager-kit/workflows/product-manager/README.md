# 产品经理工作流

这里放产品经理角色相关工作流，例如需求到 PRD、用户反馈到功能机会、竞品资料到产品分析。

## 当前可用工作流

- `product-manager-workflow.md`：产品经理总入口工作流，用于判断任务类型、调度细分工作流，并说明输出与后续流转。
- `requirement-analysis-workflow.md`：需求分析工作流，用于把想法、需求草稿、会议纪要或用户反馈整理成结构化需求分析。
- `prd-generation-workflow.md`：PRD 生成工作流，用于把需求分析结果转化为可被设计、开发和测试承接的 PRD 初稿。
- `acceptance-criteria-workflow.md`：验收标准生成工作流，用于把 PRD、功能说明和功能清单转化为可验证的完成标准。
- `feature-planning-workflow.md`：功能规划工作流，用于把产品目标、PRD 和功能清单整理成可执行的功能范围和优先级。
- `user-story-workflow.md`：用户故事生成工作流，用于把 PRD、用户场景和功能清单转化为用户视角的故事表达。
- `user-feedback-workflow.md`：用户反馈整理工作流，用于把零散反馈整理成问题、痛点、需求机会和优先级线索。
- `competitor-analysis-workflow.md`：竞品分析工作流，用于把竞品资料整理成差异点、可借鉴点、风险和产品机会。
- `priority-decision-workflow.md`：优先级判断工作流，用于在多个需求、功能或产品机会之间做可解释的取舍。
- `version-planning-workflow.md`：版本规划工作流，用于把产品目标、功能规划和优先级判断整理成阶段化版本路线。
- `product-strategy-workflow.md`：产品策略判断工作流，用于判断产品方向、机会点或策略主题是否值得推进。
- `requirement-pool-workflow.md`：需求池管理工作流，用于管理需求来源、状态、流转和后续动作。
- `product-roadmap-workflow.md`：产品路线图工作流，用于规划中长期产品方向、阶段主题和关键事项。
- `requirement-change-evaluation-workflow.md`：需求变更评估工作流，用于评估新增需求、范围变化和优先级调整对当前项目的影响。
- `version-retrospective-workflow.md`：版本复盘工作流，用于复盘版本目标达成、需求交付、变更影响、质量问题和后续改进。

## 使用建议

如果还不确定具体产品任务属于哪一类，先使用 `product-manager-workflow.md` 作为总入口。

如果任务已经明确，例如生成 PRD、整理用户反馈或做竞品分析，后续可以在本目录下继续补充更细分的工作流。
