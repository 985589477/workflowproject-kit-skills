# 产品路线图评分表

## 适用对象

用于评估产品路线图输出是否目标清晰、阶段合理、可解释、可沟通，是否可以进入 PRD、版本规划、开发排期或团队对齐。

## 评分维度

| 维度 | 分值 | 评估标准 |
| --- | --- | --- |
| 目标清晰度 | 5 | 是否明确路线图服务的产品目标和业务目标 |
| 时间范围清晰度 | 5 | 是否明确季度、半年、年度或其他时间范围 |
| 阶段主题完整性 | 5 | 每个阶段是否有主题、目标和关键事项 |
| 取舍合理性 | 5 | 是否说明进入和不进入路线图的内容与原因 |
| 演进逻辑 | 5 | 阶段之间是否有合理递进关系 |
| 风险与假设管理 | 5 | 是否保留依赖、风险、假设和待确认问题 |
| 下游衔接能力 | 5 | 是否能进入 PRD、版本规划、开发排期或团队沟通 |

总分：35 分。

## 结果判断

| 分数 | 判断 |
| --- | --- |
| 31-35 | 可以作为路线图使用 |
| 25-30 | 基本可用，但需要补充阶段依据或风险 |
| 18-24 | 需要重新整理路线图 |
| 0-17 | 不建议进入后续产品流程 |

## 扣分规则

- 没有路线图目标：扣 5 分。
- 没有时间范围：扣 5 分。
- 只是功能列表，没有阶段主题：扣 5 分。
- 所有需求都进入路线图：扣 3-5 分。
- 没有依赖和风险：扣 3 分。
- 没有后续动作：扣 3 分。
