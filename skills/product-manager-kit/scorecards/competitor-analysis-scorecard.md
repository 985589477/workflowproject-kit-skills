# 竞品分析评分表

状态: draft
版本: v1
适用对象: 产品经理竞品分析输出

## 适用场景

用于评审以下文件是否合格：

```text
{目标文档目录}/competitor-analysis.md
```

## 评分维度

每项 1 到 5 分。

| 维度 | 评分说明 |
| --- | --- |
| 目标清晰 | 是否明确本次竞品分析目标和分析范围。 |
| 事实准确 | 是否标记资料来源，是否区分事实和推断。 |
| 总体链路 | 是否能用从输入到交付的链路解释竞品如何完成用户任务。 |
| 能力分层 | 是否能抽象产品能力层级，而不是只罗列功能按钮。 |
| 功能拆解 | 是否能拆解竞品功能模块、用户场景和关键动作。 |
| 用户视角 | 是否说明不同用户类型的目标、高频功能和核心价值。 |
| 差异洞察 | 是否能提炼差异点，而不是只罗列功能。 |
| 借鉴与风险 | 是否同时说明可借鉴点和不能照搬的风险。 |
| 下游可用性 | 是否能进入需求分析、产品策略或功能规划。 |

## 总分判断

```text
36-40 分：可以进入需求分析、产品策略或功能规划。
30-35 分：可以进入下一阶段草稿，但必须补充薄弱项。
20-29 分：需要补充竞品资料或分析维度后再进入下一阶段。
19 分及以下：不建议进入下一阶段，应重新做竞品分析。
```

## 评审输出格式

```md
# 竞品分析评审

## 总体结论

## 分项评分

| 维度 | 分数 | 说明 |
| --- | --- | --- |

## 主要优点

## 主要问题

## 必须补充的问题

## 是否建议进入下一阶段

## 后续建议
```

## 不合格信号

- 只罗列竞品功能。
- 没有总体能力链路。
- 没有产品能力层级。
- 没有用户类型视角。
- 没有分析目标。
- 没有资料来源。
- 把 AI 推断写成事实。
- 只写可借鉴点，不写风险。
- 没有产品机会或后续建议。
