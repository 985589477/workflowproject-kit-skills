# 验收标准评分表

状态: draft
版本: v1
适用对象: 产品经理验收标准输出

## 适用场景

用于评审以下文件是否合格：

```text
{目标文档目录}/acceptance-criteria.md
```

## 评分维度

每项 1 到 5 分。

| 维度 | 评分说明 |
| --- | --- |
| 功能覆盖 | 是否覆盖 PRD 或功能说明中的核心功能。 |
| 可验证性 | 每条验收标准是否可观察、可执行、可判断通过或不通过。 |
| 来源追溯 | 每条验收标准是否能追溯到功能、场景或产品目标。 |
| 异常覆盖 | 是否覆盖异常流程、错误状态和无结果状态。 |
| 边界覆盖 | 是否覆盖空状态、边界值、长文本、缺失数据等情况。 |
| 下游可用性 | 是否能被测试、开发或上线验收继续承接。 |

## 总分判断

```text
26-30 分：可以进入测试用例或开发验收。
21-25 分：可以进入下一阶段草稿，但必须补充薄弱项。
16-20 分：需要补充验收标准后再进入下一阶段。
15 分及以下：不建议进入下一阶段，应重新生成验收标准。
```

## 评审输出格式

```md
# 验收标准评审

## 总体结论

## 分项评分

| 维度 | 分数 | 说明 |
| --- | --- | --- |

## 主要优点

## 主要问题

## 必须补充的问题

## 是否建议进入下一阶段

## 后续建议
```

## 不合格信号

- 验收标准只重复功能描述。
- 使用“体验好”“页面清晰”等主观描述。
- 没有操作步骤或预期结果。
- 没有异常状态。
- 没有空状态或边界情况。
- 无法判断通过或不通过。
