# 未来函数与边界用例

> 这一章解决的问题：**回测很赚钱，实盘对不上** —— 90% 出在这两类问题上。

## A. 未来函数（lookahead）：信号用了「当时还不知道」的数据

### A1. 五种典型形态

| # | 形态 | 例子 | 正确做法 |
|---|---|---|---|
| 1 | **全序列统计** | `z = (x - mean(all))/std(all)`、全序列 `max/min`、整段归一化后再取最后一根 | 只用 `[:t+1]` 的滚动窗口 |
| 2 | **估算下一根** | `estimate_next_ma(bars)`、`next_ma_break_even_price`、「用最新价推算明日」 | 可以用于**展示/预估**，**不得**进入回测信号路径 |
| 3 | **当日收盘做盘中决定** | 用当日 `close` 判断"现在该不该买" | 盘中只能用已确认数据（前一根收盘 / 分钟数据），并显式带 `as_of` |
| 4 | **生存偏差** | 用「今天的成分股/行业分类」回测三年前 | 用当时的成分/分类快照 |
| 5 | **复权口径混用** | 信号用后复权价格、成交价用不复权；或除权日跨口径比较 | 全链路统一一种复权口径，并在口径表里写明 |

### A2. 三条机械检查（评审必做）

1. **查危险函数名**：`estimate_` / `next_` / `forecast_` / `predict_` / `future` 出现在策略/回测信号路径里吗？（出现即需解释，通常应改为"只用于展示"）
2. **查全序列统计**：有没有 `max(...)` / `min(...)` / `mean(...)` / 分位数作用在**整段序列**上、再取 `[-1]`？（应改成滚动窗口）
3. **查"今天"的定义**：任何用到"当前"的地方，`as_of` 是什么？收盘后跑 vs 盘中跑，结论会不会不同？

> 前两类都能用 grep + 守卫测试机械拦住（见模板），第三类只能靠评审 —— 所以**必须写进 docstring**：「本函数假设输入序列截止到 t，不含 t 之后」。

### A3. 守卫怎么写（可执行）

`templates/signal_guard_test.py` 提供骨架，四条检查：

1. **信号函数必须在口径表里登记**（函数名 → 登记行双向一致）
2. **危险函数名不得出现在回测信号路径**（白名单承接存量，新出现即失败）
3. **判据函数不得内联进策略**（策略文件里出现阈值字面量 + 比较运算 → 警告）
4. **每个登记判据必须有对应 golden 用例**（少一条即失败）

用**白名单**而不是"一次全改"：存量列进清单，新判据必须合规。这样守卫当天就能跑，且不会因为存量违规而永远红着（红着的门禁等于没有门禁）。

## B. 边界用例清单（每个新判据逐条过）

| 场景 | 要问什么 | 期望行为（三选一，必须写清） |
|---|---|---|
| 样本不足 | 不足 N 根怎么办？ | 返回 `None`（判不了）/ `False`（不成立）/ 跳过该票 |
| 停牌 | 无量、无成交、字段为 0 | 跳过；不得当成"缩量" |
| 一字板 | 涨停/跌停、开=高=低=收 | 不可成交 → 不得计入成交信号 |
| 涨跌停但可成交 | 不是一字板，只是触及板价 | 可成交，但滑点要按最坏情况估 |
| 除权除息日 | 价格跳空不是行情 | 用复权口径判断趋势；成交价用不复权 |
| 复权口径 | 前/不/后，是否全链路统一 | 跨口径比较 = 直接拒绝 |
| 新股 | 上市不足 N 天、前 N 天波动异常 | 剔除或显式降权 |
| ST / 退市整理 | 涨跌幅限制不同（5% / 10% / 20%） | 「涨幅 ≥ 9.8%」这类阈值必须按板块调整 |
| 板块差异 | 主板 10% / 创业板科创板 20% | 阈值不能全市场一个数 |
| 数据缺口 | 缺失交易日、字段 null | 显式跳过，不得用 0 填补 |
| 大盘/板块数据缺失 | 指数停更、行业分类变更 | 降级为"个股级判断"并标注 |
| 盘中 vs 收盘 | `as_of` 是什么 | 两者结论不同时必须分开写 |

> 阈值类判据（9.8%、1.5–3 倍、30–50%）**每一条都要问：换了板块/市场还成立吗**。

## C. golden 用例的写法

1. **用合成数据，不用真实行情**：可控边界，也避免把受版权保护的数据/私有语料提交进仓库。
2. **断言到值级**，不要只断言"有结果"：`assert r["breakout_percent"] == pytest.approx(1.5)`。
3. **一个断言一个概念**：数据不足、量能不够、幅度不够分开测。
4. **必须能注入违规变红**：把阈值改掉 1，测试要红 —— 不红的测试是装饰。
5. **golden 要冻结**：把输入 → 输出的哈希存成文件，改动导致结论变化时必须显式更新哈希（而不是静默通过）。

## D. 什么时候可以相信这个信号

三条都满足才算"可用"：

1. **无未来函数**：A2 三条检查通过。
2. **边界已定义**：B 清单里与本判据相关的每一行都有明确行为。
3. **参数不敏感**：阈值 ±20% 波动时，结论不会从"能赚"翻成"亏" —— 会翻就说明是过拟合，不是信号。
