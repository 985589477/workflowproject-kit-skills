# 设计系统检查评分表

适用对象：设计系统检查、规范审计、风格一致性检查

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 规范识别 | 20 | 是否识别品牌、颜色、字体、间距、组件和布局规范 |
| 缺失判断 | 20 | 是否明确缺失、冲突和过时规范 |
| 任务约束 | 20 | 是否说明本次设计必须遵守和可以扩展的规范 |
| 风险识别 | 20 | 是否识别一致性、复用、状态和适配风险 |
| 落地建议 | 20 | 是否给出设计、开发、测试可执行建议 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可作为设计前置检查依据 |
| 75-89 | 可试用，需要补充少量规范 |
| 60-74 | 规范依据不足，不建议直接设计 |
| 0-59 | 需要重新梳理设计系统 |
