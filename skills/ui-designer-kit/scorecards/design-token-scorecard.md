# 设计令牌与平台适配评分表

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 平台确认 | 15 | 是否确认目标平台、框架和主题接入方式 |
| 平台中立性 | 20 | 是否有独立于 CSS 或单一框架的令牌源文件 |
| 令牌完整性 | 20 | 是否覆盖颜色、字体、间距、圆角、状态和组件需要的令牌 |
| 语义化 | 15 | 是否使用语义令牌，避免组件直接散落原始值 |
| 平台适配 | 15 | 是否明确平台映射、单位、字体、主题和能力差异 |
| 开发交接 | 15 | 是否说明实现文件、可调整范围和不可变更边界 |

## 通过标准

- 90-100：可进入开发交接。
- 75-89：补充平台差异后可试用。
- 60-74：需要补充令牌或适配说明。
- 0-59：不通过，不能直接进入开发。
