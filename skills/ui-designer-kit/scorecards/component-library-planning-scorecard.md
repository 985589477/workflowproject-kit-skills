# 组件库规划评分表

适用对象：组件库规划、组件清单、组件复用方案

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 组件分层 | 20 | 是否区分基础组件、业务组件和组合组件 |
| 复用边界 | 20 | 是否说明复用、扩展、新增的判断依据 |
| 状态和变体 | 20 | 是否覆盖组件状态、尺寸、密度、权限和端差异 |
| 多端适配 | 20 | 是否说明不同端和特殊设备下的组件变化 |
| 开发交接 | 20 | 是否包含数据、状态、实现和验收关注点 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可进入设计系统或开发组件建设 |
| 75-89 | 可试用，需要补少量细节 |
| 60-74 | 不建议直接建设组件库 |
| 0-59 | 需要重新拆分组件 |
