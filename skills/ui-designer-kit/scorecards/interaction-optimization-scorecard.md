# 交互体验优化评分表

适用对象：交互优化方案、可用性问题修复、设计评审和开发交付复核。

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 用户目标 | 15 | 是否明确用户、任务、成功条件和任务重要程度 |
| 路径效率 | 20 | 是否识别多余步骤、决策成本、中断点和优化后的路径 |
| 操作区域 | 20 | 是否给出具体可操作区域、平台单位、间距和触达方案 |
| 反馈恢复 | 15 | 是否覆盖处理中、成功、失败、空、取消、重试和恢复 |
| 视觉层级 | 15 | 是否具体处理主次操作、字号、对比、间距、密度和一致性 |
| 多端适配 | 10 | 是否覆盖目标设备、横屏、分屏或折叠状态 |
| 交接验收 | 5 | 是否能被产品、开发和测试理解、实现和验证 |
| **总分** | **100** |  |

## 结论

- 90-100：交互方案可进入开发或验收。
- 75-89：可以试用，但需要补齐低风险问题。
- 60-74：存在明显操作风险，不建议直接交接。
- 0-59：未形成可执行方案，需要重新分析用户任务。
