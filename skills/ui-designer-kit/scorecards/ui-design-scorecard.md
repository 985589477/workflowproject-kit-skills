# UI 设计输出评分表

适用对象: UI brief、页面结构、组件说明、交互状态说明

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 目标和用户场景 | 20 | 是否明确页面目标、目标用户和核心使用场景 |
| 信息架构 | 20 | 是否清楚说明信息优先级、页面区块和内容关系 |
| 组件和状态 | 20 | 是否覆盖关键组件、交互状态和异常状态 |
| 可用性 | 15 | 是否识别操作路径、操作热区、反馈、空态、错误、恢复和可访问性风险 |
| 视觉一致性 | 15 | 是否考虑品牌、平台、设计系统或现有组件规范 |
| 交接清晰度 | 10 | 是否能被产品、开发和测试理解并继续执行 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可进入设计或开发交接 |
| 75-89 | 可试用，需要补充少量信息 |
| 60-74 | 待补齐，不建议直接交接 |
| 0-59 | 不通过，需要重新整理输入 |
