# 设计到开发实现约束评分表

适用对象：设计开发交接、实现约束、开发验收说明

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 页面结构 | 20 | 是否说明布局容器、断点、导航和操作区 |
| 组件实现 | 20 | 是否说明组件来源、数据字段、状态和实现注意事项 |
| 状态异常 | 20 | 是否覆盖加载、空态、错误、权限和极端数据 |
| 多端适配 | 20 | 是否覆盖响应式、横屏、平板、折叠屏、分屏和双屏 |
| 验收清晰度 | 20 | 是否给出开发可调整范围和验收清单 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可进入开发实现 |
| 75-89 | 可开发，需要补少量交接项 |
| 60-74 | 开发风险较高，需要补齐 |
| 0-59 | 不建议交给开发 |
