# 页面类型设计模式评分表

适用对象：页面模式、页面骨架、页面类型设计

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 页面类型判断 | 20 | 是否准确判断页面类型和用户主任务 |
| 页面骨架 | 20 | 是否说明导航、主内容、操作、辅助和反馈区域 |
| 组件组合 | 20 | 是否说明核心组件组合和复用规则 |
| 多端变化 | 20 | 是否说明不同端页面结构和信息降级 |
| 适用边界 | 20 | 是否说明适用和不适用场景 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可作为页面设计模式复用 |
| 75-89 | 可试用，需要补少量场景 |
| 60-74 | 模式不够稳定 |
| 0-59 | 需要重新判断页面类型 |
