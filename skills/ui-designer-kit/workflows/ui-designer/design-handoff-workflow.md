# 设计交接工作流

## 目的

把 UI 设计输出整理成产品、开发、测试都能继续使用的交接说明。

## 适用场景

- UI 方案准备进入开发。
- 需要向开发说明页面结构、组件状态和交互规则。
- 需要向测试说明 UI 验收重点。
- 设计输出中有待确认问题、风险或后续版本范围。
- 设计涉及响应式、多端、折叠屏、分屏、双屏或 iPad 适配。

## 执行步骤

1. 汇总页面目标和设计范围。
2. 汇总页面结构、组件和状态。
3. 汇总响应式、iPad、折叠屏、分屏和双屏适配规则。
4. 标记开发需要关注的实现点。
5. 标记测试需要覆盖的 UI 场景。
6. 标记待确认问题和非范围。
7. 输出交接清单和后续动作。

## 特殊设备交接要求

如果涉及折叠屏、分屏、双屏或类似 iPhoneDuo 的设备，交接给开发时必须说明：

- 目标设备形态。
- 最小可用宽度和关键断点。
- 展开态、折叠态、分屏态分别使用哪种布局。
- 是否存在铰链、中缝、分隔区或安全区域。
- 哪些组件需要避让中缝或安全区域。
- 列表、详情、筛选、弹窗、主操作在特殊形态下的位置。
- 哪些场景可以按普通响应式处理，哪些必须单独适配。
