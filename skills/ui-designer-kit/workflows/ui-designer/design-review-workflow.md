# 设计评审工作流

## 目的

评审 UI brief、页面结构、组件说明或设计稿说明是否满足产品目标、用户场景、信息架构、可用性和交接要求。

## 适用场景

- 已经有 UI 方案，需要检查是否可交接。
- 页面设计可能遗漏状态、边界或异常。
- 产品、开发、测试需要共同评审设计输出。
- 需要从设计稿中发现风险和待确认问题。

## 执行步骤

1. 对照产品目标和用户场景检查设计目标。
2. 检查信息架构是否清楚。
3. 检查关键操作路径是否闭环。
4. 检查组件状态是否完整。
5. 检查视觉和组件规范是否一致。
6. 检查可用性、可访问性和异常场景。
7. 输出通过项、问题、风险和修改建议。

## 输出

使用：

```text
06-templates/ui-designer/design-review-template.md
```
