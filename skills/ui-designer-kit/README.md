# ui-designer-kit

导出时间：2026-10-14

`ui-designer-kit` 是从 WorkflowProject 导出的 UI 设计能力包。

它用于把产品需求、PRD、页面想法、竞品界面或交互问题整理成可交接的 UI brief、设计规范确认、设计系统检查、响应式适配方案、页面类型模式、页面结构、组件库规划、交互状态说明、交互体验优化、可访问性与可用性检查和开发实现约束。

设计规范输出必须具备组件意识和通用适配规则，不应只停留在颜色、风格或“需要响应式”的抽象描述。

涉及折叠屏、分屏、双屏或类似 iPhoneDuo 的设备时，必须在设计交接和开发实现约束中写清适配方式。

## 最快使用

```text
请使用 ui-designer-kit 处理我的设计任务：{写下你的任务}
```
