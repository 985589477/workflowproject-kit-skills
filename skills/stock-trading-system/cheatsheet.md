# 一页速查（买前 / 持仓 / 卖出）

> 只在需要快速自查时读这一页；根因解释见 `SKILL.md` 的章节路由。

## 1. 买入前 8 问

| 检查项 | 必问问题 |
|---|---|
| 主线 | 这个板块是主线、结构性主线，还是普通题材？ |
| 催化 | 催化能否影响业绩预期，还是只有情绪？ |
| 时间 | 是否经过「连续 3 天异动」或「7 交易日 3 次异动」验证？ |
| 权重 | 板块权重是否走出 2–4 周以上趋势？ |
| 个股 | 是否远离套牢区、放量合理、60 日均线向上？ |
| 位置 | 是否有明确的支撑、压力、防守位？ |
| 买点 | 属于哪一类买点，确认信号是什么？ |
| 风控 | 如果判断错，跌破哪里必须走？ |

## 2. 持仓中 7 问

1. 趋势线是否仍然有效？
2. 回调是缩量，还是放量阴线？
3. 洗盘有没有破坏大结构？
4. 是否进入 30%–50% 的常见洗盘区？
5. 是否出现「加速后放量阴线」？
6. 分时是否出现频繁急涨急跌？
7. 板块权重是否仍在创新高或维持趋势？

## 3. 卖出与风控 8 条

1. 下降趋势破位 → 直接离场。
2. 放量破位 → 直接离场。
3. 高位尾盘破位 → 直接离场。
4. 强支撑共振点有效跌破 → 离场。
5. 修正趋势线破位 → 离场或大幅降风险。
6. 二高点附近出现危险 K 线（流星线/长影线/大阴线） → 高度警惕。
7. 上涨楔形假突破 → 不追高。
8. 小盘分时直线放量跳水 → 按弃庄风险处理。

## 4. 破位速查（关键：先看趋势与量能，再决定是一刀切还是给容错）

| 场景 | 信号 | 处理 |
|---|---|---|
| 下降趋势 | 任意有效破位 | 无条件离场 |
| 盘整结构 | 放量跌破支撑 | 直接离场 |
| 盘整结构 | 缩量跌破支撑 | 观察 3 天，看能否重新站回 |
| 上涨趋势 | 放量跌破关键趋势/支撑 | 直接离场 |
| 上涨趋势 | 缩量跌破、结构未完全坏 | 给容错窗口，等后续 K 线确认 |
| 高位尾盘 | 尾盘砸盘跌破 | 直接离场 |
| 低位尾盘 | 破位但利润空间不足 | 多看一天，次日放量阴线再确认 |
| 小盘分时 | 直线放量跳水 | 弃庄式盘口，优先风控 |

## 5. 七类买点一表

| 买点 | 核心逻辑 | 合格信号 | 主要风险 |
|---|---|---|---|
| 启动买点 | 买吃货/蓄势/试盘后的确定点 | 主线板块上涨、个股放量突破、分时堆量 | 只看涨幅追高，忽略结构 |
| 换手买点 | 解放散户筹码，意在拉升 | 低位大长腿、杯柄、大换手、大成交量 | 高位同形态可能是诱多出货 |
| 三低票 | 低价、小盘、筹码干净，游资短线 | 价格约 10 元、市值约 30–50 亿、前期超跌 | 一波流，纪律要求极高 |
| 独立行情票 | 强主力控盘，不受主线约束 | 初期放量、后期缩量，沿 5/10 日线震荡上行 | 后期主力难出货，小盘易闪崩 |
| V 型反转 | 大刺激/新生事物带来机构重估 | 三根放量大阳，回落后再放量阳线 | 频率低，需机构预期一致 |
| 盘整突破 | 盘整结束，重新打开空间 | 箱体/三角形突破，属上涨中的空中加油 | 高位翻倍后突破容易诱多 |
| 左右侧买点 | 回调企稳后的右侧确认 | 三根 K 线不创新低；阳包阴（子母线）确认 | 支撑未稳就提前介入 |

## 6. 一页复盘卡

> **主线**：主线不是猜出来的，是消息、时间、板块特征和权重趋势一步步校验出来的。
> **选股**：脱离主线的技术形态，持续性通常不足；先看主线，再看个股。
> **买点**：买在确定点，不买最低点；确定点来自吃货、蓄势、试盘、突破或回调确认。
> **主升**：起涨初期筹码最稳定；30%–50% 区间常见洗盘和分歧。
> **风控**：放量破位、高位尾盘破位、强支撑共振点跌破，都要严格执行。
> **见顶**：小盘票见顶可以是一根阴线，大盘票见顶常是一个区域；不要把鱼尾当主升。
