# 图形划线 · 买点体系

> 对应决策链第 3、4 段。**先有防守位，再谈买点。**

## A. 划线：不是为了预测，是为了找机会、定防守、执行风控

### A1. 线型速查

| 线型 | 作用 | 关键要点 |
|---|---|---|
| 原始趋势线 | 判断股价运行大方向 | **趋势线越平坦，实战效果越差** |
| 修正趋势线 | 控仓位、评估风险、捕捉机会 | 更贴近实际操作；**破线要重视**（价格常高于原始线） |
| 下颈线 | 判断吸筹区域、筹码分布、市场成本 | 行情高点通常对应密集成交区 |
| 上颈线 | 识别顶部第一次转折点 | 接触点位越多，参考意义越强 |
| 支撑线 | 上涨回调中的买点参考 | 前高、前低、箱体下沿/上沿 |
| 压力线 | 上行阻力位置 | 前高和箱体上沿最常用 |
| 黄金分割线 | 辅助判断支撑 | 只做技术参考，**不单独作为买点** |

### A2. 每条线的可执行含义

**趋势线**
- 线上出现 **5 浪结构**；破线 → 控制仓位。
- 上升趋势线被破 = 资金逐步离场；下降趋势线被破 = 资金逐步进场。
- **强支撑位左侧买点信号**：上涨趋势中，趋势线支撑处的回调企稳。

**水平颈线**
- 上破上颈线 = 行情启动；下破下颈线 = 行情结束。

**支撑线**
- 本质是**上涨趋势中的节奏控制线**，也是回调区域的企稳点。
- 常引用位置：箱体上沿/下沿、前高点附近/前低点附近。

**黄金分割线**（取一波拉升波段的低点 → 高点）

| 分割位 | 解读 |
|---|---|
| 23.6% | 不跌破即保持上升趋势，且一般会创新高 |
| 38.2% | 不筑底、无量 → 可能是反抽，容易形成二高点 |
| 50% | **关键位**：跌破即意味着行情结束，跌幅较深，容易走 abc 调整 |

### A3. 技术共振点（最关键的一类位）

> **核心**：多条技术线交叉形成的强支撑位置 = 关键防守位。
> **红线**：强支撑共振点一旦**有效跌破，必须执行离场**。
> 典型：支撑线与趋势线的交叉点 —— 跌破必须离场。

早盘破位的分辨：

- 上涨趋势中的**早盘杀跌多是洗盘**。
- 分时出现**二次出货 / 下穿分时均线 / 虚拟量能对应日线放大量** → 离场。

## B. 买点体系

### B1. 总原则

> 买点不追求买在最低点，而是**买在主力吃货付出时间成本后的确定点**。

排序：① 大盘环境 → ② 主线板块是否持续 → ③ 个股技术结构 → ④ 盘口/量能/确认 K 线。

### B2. 七类买点速查

| 买点 | 核心逻辑 | 合格信号 | 主要风险 |
|---|---|---|---|
| 启动买点 | 吃货/蓄势/试盘后的确定点 | 主线板块上涨、个股放量突破、分时堆量 | 只看涨幅追高、忽略结构 |
| 换手买点 | 解放散户筹码，意在拉升 | 低位大长腿、杯柄、大换手、大成交量 | 高位同形态 = 诱多出货 |
| 三低票 | 低价、小盘、筹码干净，游资短线 | 低价约 10 元、30–50 亿、前期超跌 | 一波流，纪律要求高 |
| 独立行情票 | 强主力控盘，不受主线约束 | 初期放量、后期缩量，沿 5/10 日均线震荡上行 | 主力难出货；小盘易闪崩 |
| V 型反转 | 大刺激/新生事物带来机构重估 | 三根放量大阳，回落后再放量阳线 | 频率低（约一年一次），需机构预期一致 |
| 盘整突破 | 盘整结束，重新打开空间 | 箱体/三角形突破（上涨中的空中加油） | 高位翻倍后突破容易诱多 |
| 左右侧买点 | 回调企稳后的确认 | 三根 K 线不创新低；阳包阴（子母线） | 支撑未稳就提前介入 |

### B3. 启动买点的三步倒推

1. **吃货区域**：连续阳线、阳线集中、多为小阳线带上下影；**阳线放量、阴线缩量**（与之前平均量能对比）；技术形态规整易识别；主力**不破坏自己的吃货成本区**；分时图有堆量、有扫货行为。
2. **蓄势区域**：在压力位**窄幅震荡**，成交量进一步放量，**股价不回落**。
3. **试盘信号**：早盘快速拉升回落（出现在盘中/尾盘则属**攻击失败**）；位置在低位；频繁上引线但整体结构最终形成突破。

必须同时确认的启动背景：

- **大盘好** + **板块是市场主线且上涨趋势** + **个股上涨趋势**。
- 启动点是**第一买点**，要求涨幅超过 6 个点。

容易混淆的形态（位置决定结论）：

| 形态 | 区别 |
|---|---|
| 试盘线 | 在低位、压力位窄幅震荡、放量不回落 |
| 遇阻 | 有一波拉升背景、股价在高位 |
| 流星线 | 有连续拉升背景、股价在高位 |

**位置判定（同一形态结论相反）**：

- 大盘票：**100% 中位**算可接受，**200%–300% 属于高位**。
- 小盘票：**30% 已是高位**；低位形态在高位出现 = **诱多出货 / 拉尾盘**。

### B4. 低位换手买点（解放筹码 → 意在拉升）

必要条件：

1. 位置处于低位（高位同形态按诱多出货处理）。
2. 有过**大换手 + 大放量**。
3. 解放近期套牢盘。
4. 低位大长腿，最好能够**封板**。
5. 分时盘口剧烈波动但不破坏大结构；此前有过**连续吃货（碎阳线）**。

### B5. 盘整突破买点

**杯柄/箱体** 的图形要件：

- 挖坑洗盘**不破坏技术形态、不破坏吃货区低点**。
- 有修复结构：前高分歧后封板，或承接盘口的大阳线 → 之后出现振荡小 K 线 → 再放量上攻，**这根放量大阳线是极好的买点**。

背景要求（不满足则不成立）：

1. 一定是**一波上升趋势中的调整**。
2. 回调盘整**不能跌破上涨波段的 1/2**（跌破 = 该股行情结束）。
3. 盘整时间的极限时长 ≈ 拉升波段的时长。
4. 盘整过长 → 横久可能下跌；盘整**超长**后突破 → 容易上涨（前提是结构没坏）。
5. **上涨空间不能过大**：股价已翻倍后在高位做箱体突破 = 诱多出货。

盘整类型：

| 类型 | 判据 |
|---|---|
| 箱体盘整（空中加油） | 单一上涨趋势中的短期强势盘整，**7–8 个交易日**；横盘箱体上颈线的突破 = **三浪主升开始** |
| 三角形盘整 | 上升/下降/收敛三角形；**三角形突破是买点，代表三浪主升开始** |

### B6. 左右侧买点

| 类型 | 确认信号 |
|---|---|
| 左侧 | 上涨回调企稳；**三根 K 线不创新低、重心不下降**；必须带好止损，破位离场 |
| 右侧 | 在左侧信号基础上出现**阳包阴**（子母线：前面小 K 线，后面阳线包裹） |

> 强势股**禁止左侧低吸**（风险大），中大阳线反包才可进场。

### B7. 强势启动买点（小盘为主，20–50 亿常见）

- 启动方式：**快速拉离成本区**、跳空上涨、或快速封板。
- K 线特点：第一根阳线有**吃货行为 + 盘口承接 + 激发市场关注度**；第二根阳线常见**对敲/对倒**封板拉升。
- 之后**洗盘一般发生在涨幅 30%–50% 区间**，且比较剧烈（大回撤、跌停板、大长腿、假阴线）。

### B8. 三低票 / 妖股参与要点

背景要求：大盘环境相对较好 + 板块**一定是市场热点主线**。

标的要件：

- 盘子：流通市值 **30–50 亿**（主力易控盘，又保留流动性）→ 短线资金参与，**一般一波到顶**。
- 筹码干净：业绩亏损、股价超跌或阴跌、**没有主力资金进场**。
- 价格：较低，一般 **10 元左右**（容易引起散户跟风）。
- 盘口：有过**集中吃货**（分时图上能看出主动/被动吃货）；**分时图越奇怪越有机会**，代表主力仓位较大。

操作要点：打三板的前提是**前两个涨停板有过吃货**。

### B9. 独立行情票 & 机构票 V 型反转

**独立行情票**（强主力控盘，不受主线约束）

1. 主力控盘率高，通常震荡上行。
2. 斜率 **> 45°** 参考 **5 日均线**；斜率 **< 45°** 参考 **10 日均线**。
3. 量价：**初期上涨放量**（集中吃货）、**后期上涨缩量**（筹码惜售、结构稳定）。
4. 结束方式：小盘票往往**闪崩**；大盘机构票多为 V 型反转后的**缩量破位/破线阴跌**。
5. 分时快速且频繁的急涨急跌 = 典型出货盘口之一。

**机构票 V 型反转**（频率约一年一次）

- 上涨理由：大的刺激因素或新生事物，**能反映到业绩上**。
- 盘子较大，**机构辨识度高**；只做**机构预期一致**的阶段。
- 量价与技术特征：以 V 型出现，反转初期**大幅放量、无筑底特征**；技术上通常要求**三根放量大阳线**；底部放量大阳后**不会大幅回落**；回落调整结束再启动**必须再放量大阳线**（买点信号）。
- 上涨形态：**很少涨停板**，多为碎阳线/中阳线，趋势震荡缩量上行，是"吃货买上去"的。
- 卖出：按趋势线操作，**破线即离场**；机构票结束**不会出现集中出货的 K 线**，而是以分歧方式震荡缩量下跌、破线。
