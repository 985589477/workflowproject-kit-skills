# 开发工程师模板

这里放开发角色模板，例如项目启动治理、项目理解、实现方案、调试计划、代码审查、测试用例生成。

## 当前模板

| 模板 | 用途 |
| --- | --- |
| `project-bootstrap-template.md` | 新项目启动治理报告。 |
| `project-understanding-template.md` | 已有项目理解报告。 |
| `requirement-to-architecture-template.md` | 架构影响分析报告。 |
| `module-boundary-analysis-template.md` | 模块边界分析报告。 |
| `change-risk-assessment-template.md` | 变更风险评估报告。 |
| `impact-analysis-template.md` | 影响范围分析报告。 |
| `minimal-change-governance-template.md` | 最小必要变更治理报告。 |
| `implementation-template.md` | 实现交付说明。 |
| `testing-verification-template.md` | 测试与验收报告。 |
| `documentation-sync-template.md` | 文档同步报告。 |
| `code-review-template.md` | 代码评审报告。 |
| `architecture-decision-record-template.md` | ADR 架构决策记录。 |
| `dependency-and-tech-debt-template.md` | 依赖与技术债治理报告。 |
| `environment-config-governance-template.md` | 环境与配置治理报告。 |
| `release-and-rollback-template.md` | 发布与回滚治理报告。 |
| `ai-collaboration-retrospective-template.md` | AI 协作复盘报告。 |
| `issue-diagnosis-template.md` | 问题定位报告。 |
| `data-api-contract-template.md` | 数据/API/状态契约报告。 |
| `security-permission-template.md` | 安全与权限治理报告。 |
| `workflow-orchestration-template.md` | 开发工作流协同编排记录。 |
