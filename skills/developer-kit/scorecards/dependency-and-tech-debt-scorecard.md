# 依赖与技术债治理评分表

状态: draft
版本: v1
适用对象: developer-kit 依赖与技术债治理报告

## 适用场景

用于评估 AI 对新增依赖、依赖调整、临时方案和技术债的治理判断是否可靠。

## 评分维度

每项 1 到 5 分。

| 维度 | 评分说明 |
| --- | --- |
| 对象分类 | 是否明确属于新增、升级、替换、移除依赖，还是临时方案或技术债。 |
| 必要性 | 是否判断已有能力、标准库、自研和新增依赖的取舍。 |
| 备选方案 | 是否列出多个方案并比较优缺点、成本和风险。 |
| 依赖风险 | 是否评估安全、许可证、维护、体积、性能、兼容性和锁定风险。 |
| 技术债记录 | 是否说明债务原因、影响范围、风险等级、短期收益和长期成本。 |
| 偿还计划 | 是否给出偿还方案、触发条件和最晚处理时机。 |
| 验证回滚 | 是否说明验证要求、回归范围和回滚方案。 |
| ADR 判断 | 是否判断高影响依赖或技术债是否需要进入 ADR。 |

总分：40 分。

## 总分判断

```text
36-40 分：治理判断充分，可以作为依赖或技术债处理依据。
30-35 分：基本可用，但需要补充风险、偿还计划或验证。
22-29 分：治理不足，容易留下长期维护风险。
21 分及以下：需要重新评估。
```

## 评审输出格式

```md
# 依赖与技术债治理评审

## 总体结论

## 分项评分

| 维度 | 分数 | 说明 |
| --- | --- | --- |

## 主要优点

## 主要问题

## 必须补充的问题

## 是否建议执行治理方案

## 后续建议
```

## 不合格信号

- 新增依赖没有必要性说明。
- 没有备选方案。
- 没有安全、许可证或维护风险评估。
- 临时方案没有偿还条件。
- 技术债只有描述，没有偿还计划。
- 没有验证或回滚要求。
- 高影响决策没有判断是否需要 ADR。
