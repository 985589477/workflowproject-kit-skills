# 环境与配置治理评分表

状态: draft
版本: v1
适用对象: developer-kit 环境与配置治理报告

## 适用场景

用于评估 AI 对环境变量、启动配置、构建配置、部署配置和环境差异的治理判断是否可靠。

## 评分维度

每项 1 到 5 分。

| 维度 | 评分说明 |
| --- | --- |
| 配置对象 | 是否明确本次涉及环境变量、命令、部署、CI、容器、外部服务或安全配置。 |
| 现有配置 | 是否读取并总结现有配置文件、说明文档和技术栈入口。 |
| 配置项清单 | 是否说明配置项用途、必填性、默认值、适用环境和缺失后果。 |
| 环境差异 | 是否说明本地、测试、预发、生产环境差异。 |
| 风险识别 | 是否识别敏感信息、生产、权限、安全、支付、数据、构建和部署风险。 |
| 治理方案 | 是否给出 `.env.example`、配置文档、启动说明、CI/CD 或部署文档建议。 |
| 验证回滚 | 是否说明启动、构建、测试、连接、部署前检查和回滚要求。 |
| 文档同步 | 是否说明哪些配置文档需要同步。 |

总分：40 分。

## 总分判断

```text
36-40 分：配置治理充分，可以作为配置变更依据。
30-35 分：基本可用，但需要补充环境差异、风险或验证。
22-29 分：治理不足，容易导致启动、构建或部署问题。
21 分及以下：需要重新评估配置变更。
```

## 评审输出格式

```md
# 环境与配置治理评审

## 总体结论

## 分项评分

| 维度 | 分数 | 说明 |
| --- | --- | --- |

## 主要优点

## 主要问题

## 必须补充的问题

## 是否建议执行配置变更

## 后续建议
```

## 不合格信号

- 写入真实密钥或敏感信息。
- 没有说明配置用途和缺失后果。
- 没有区分环境差异。
- 生产或安全配置没有风险确认。
- 没有验证和回滚要求。
- 没有文档同步建议。
