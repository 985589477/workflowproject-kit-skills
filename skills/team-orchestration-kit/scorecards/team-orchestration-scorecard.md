# 跨角色团队总调度评分表

适用对象：跨角色团队调度计划、角色协作流、交接验收和 badcase 反馈。

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 角色判断 | 20 | 是否准确判断产品、UI、开发、测试哪些角色需要参与 |
| 阶段顺序 | 20 | 是否按合理优先级推进，而不是跳过必要上游 |
| 交接检查 | 20 | 是否检查上游产物能否被下游角色理解 |
| 互相验收 | 20 | 是否检查开发交付能否通过产品、UI、测试验收 |
| badcase 反馈 | 20 | 是否能识别沟通问题并建议回到对应能力项目优化 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可作为团队总调度执行 |
| 75-89 | 可试用，需要补少量交接细节 |
| 60-74 | 协作链路不完整，不建议直接执行 |
| 0-59 | 需要重新判断角色和阶段 |
