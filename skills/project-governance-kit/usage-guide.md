# 使用指南

## 第一次使用

把 `project-governance-kit/` 放到真实项目根目录或项目统一 AI 能力目录，然后阅读 `START-HERE.md`。

## 有文档的项目

让 AI 先检查已有规则和文档，再根据项目事实开发。不要让通用能力包覆盖项目已经确认的架构和规范。

## 没有文档的项目

让 AI 输出缺口清单，并选择最小治理集：

```text
README.md
项目规则入口
架构概览
模块地图和边界
设计规范或设计假设
任务列表
验证规则
项目记忆摘要
```

## 何时调用角色包

- 需求目标和验收不清：产品经理。
- 页面、组件、视觉和设备适配不清：UI 设计师。
- 架构、模块和代码实现需要判断：开发工程师。
- 测试、回归和发布质量需要判断：测试工程师。

项目治理检查本身不需要调用所有角色。
