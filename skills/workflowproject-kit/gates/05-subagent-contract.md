# 门禁 05：子 Agent 契约与父 Agent 复核

**触发**：① 创建任何子 Agent 之前；② 收到任何子 Agent 报告之后。

**为什么**：子 Agent 的报告会被当成事实写进方案。**如果父 Agent 不复核，方案的质量上限
就是子 Agent 的准确度。** 原 kit 要求给子 Agent"明确的任务简报、文件边界和验收标准"，
但 `复核|抽样验证` 全仓仅 **1 命中** —— **没有要求父 Agent 复核**。

**我实测的结果**：我亲手复核了子 Agent 报告里约 40 条结论，抓出：
- 审计报告**2 个夸大的数字**（"140 处 hex"实测 36 处；"某 `:root` 100% 被覆盖"实际它独有 `font-family`）
- 1 个我**自己差点犯的错**：报告建议删掉一个 128MB 索引，实测它**非冗余**（查询计划器实际在用它）

**这三条如果没复核，都会变成方案里的错误内容。**

---

## 必须产出 A：创建前的简报（模板：`templates/subagent-brief.md`）

简报必须含 6 项，缺一项就重写：

1. **目标**：一句话，可判断完成与否
2. **可写边界**：明确文件/目录白名单（多个子 Agent 并行时**互不重叠**）
3. **只读范围**：可以读但不能改的地方
4. **验收标准**：什么算完成
5. **返回格式**：见下
6. **禁止事项**：例如"不要改代码，只报告"

## 必须产出 B：返回契约（硬性）

子 Agent 的报告必须结构化，且**每条结论带证据**：

```markdown
## 结论
- {结论} —— 证据：`{文件}:{行}` 或 `{命令} → {结果}`

## 计数与统计
- {指标}: {数字}（统计方式：{命令}）

## 未验证 / 不确定
- {我推断但没验证的}：{为什么没验证，需要谁验证}
```

**「未验证」段是强制的**——不允许把推断混在结论里。没有这一段的报告，**打回重做**。

## 必须产出 C：父 Agent 的复核记录

收到报告后，父 Agent **必须**：

1. **抽样复核**（不必全查，但**数字类断言必须全查**：
   所有计数、百分比、行数、性能数字——这类最容易夸大且影响最大）
2. **明确记录复核了什么**，写进交付物：

```markdown
## 复核记录
- 复核了：{N} 条结论中的 {M} 条
- 发现并修正：{列表}
- 未复核：{列表}（原因）
```

## 检查方式

- 报告里有没有「未验证」段？数字有没有带统计命令？
- 交付物里有没有「复核记录」段？里面是否写了**发现并修正了什么**？
  （写"已全部核对无误"但列不出任何修正，通常意味着没真复核。）

## 反例

| 反例 | 后果 |
|---|---|
| 直接引用子 Agent 的数字写进方案 | 夸大/错误数字进入交付物 |
| 多个子 Agent 写同一批文件 | 互相覆盖，改动丢失 |
| 子 Agent 报告 5,000 字无结构 | 父 Agent 只能摘要，细节全丢 |
| 复核记录写"已核对"但无具体条目 | 不可验证，等于没复核 |
| 让子 Agent 做需要跨会话判断的事 | 它没有上下文，只能猜 |
