# AI 工作流规则

> **规则本体在 `AGENTS.md`。** 本文件只是一个**指针**，供按固定文件名查找规则的工具使用。
>
> 为什么不做成第二份规则：这两份文件**曾经内容完全相同**（生成器用同一个变量写两次），
> 结果是维护时必然漂移——改了一份忘了另一份，读的人不知道该信哪份。
> **一份内容，一个位置。**

## 门禁表

完整门禁见 kit 的 `SKILL.md`。可运行校验：

```bash
python3 <kit>/scripts/check_gates.py .          # 硬门禁
python3 <kit>/scripts/check_gates.py --audit .  # 列出哪些门禁没证据（找死规则）
```

## 为什么这条指针本身也是个门禁

如果某天你发现本文件被填回了完整规则内容，说明有人又在复制规则了 ——
**那时候应该做的不是同步两份，而是把内容合并到 `AGENTS.md` 并恢复本文件为指针。**
