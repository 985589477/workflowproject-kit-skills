# 安全与权限治理评分表

状态: draft
版本: v1
适用对象: developer-kit 安全与权限治理报告

## 评分维度

每项 1 到 5 分。

| 维度 | 评分说明 |
| --- | --- |
| 安全对象 | 是否识别登录、权限、用户数据、密钥、上传下载、支付等对象。 |
| 权限矩阵 | 是否明确角色、允许操作、禁止操作和校验位置。 |
| 敏感数据 | 是否识别敏感字段、脱敏要求和不得入库内容。 |
| 风险识别 | 是否识别越权、泄露、注入、上传、批量操作等风险。 |
| 安全约束 | 是否定义必须遵守和必须禁止的规则。 |
| 验证要求 | 是否说明权限、安全和异常路径如何验证。 |
| 确认策略 | 高风险安全变更是否要求人工确认。 |

总分：35 分。

## 总分判断

```text
31-35 分：安全权限边界清楚，可以进入后续实现。
26-30 分：基本可用，需要补充验证或权限矩阵。
18-25 分：安全风险不清，不建议实现。
17 分及以下：需要重新治理。
```

## 不合格信号

- 没有权限矩阵。
- 没有校验位置。
- 没有敏感数据处理。
- 高风险权限变更未要求确认。
- 把前端隐藏按钮当成唯一权限控制。
