# 数据/API/状态契约评分表

状态: draft
版本: v1
适用对象: developer-kit 数据/API/状态契约报告

## 评分维度

每项 1 到 5 分。

| 维度 | 评分说明 |
| --- | --- |
| 契约对象 | 是否明确接口、字段、数据模型、状态或缓存对象。 |
| 归属关系 | 是否明确提供方、消费方和责任模块。 |
| 字段定义 | 是否说明类型、必填、默认值、错误处理和边界状态。 |
| 数据流 | 是否说明触发入口、读取、转换、存储和展示链路。 |
| 兼容性 | 是否分析旧接口、旧数据、枚举变化和迁移风险。 |
| 风险识别 | 是否识别空值、权限、缓存、发布顺序和协作风险。 |
| 实现支撑 | 是否能直接支撑影响分析、实现和测试。 |

总分：35 分。

## 总分判断

```text
31-35 分：契约清楚，可以进入实现。
26-30 分：基本可用，需要补充兼容或错误处理。
18-25 分：契约不清，不建议实现。
17 分及以下：需要重新定义契约。
```

## 不合格信号

- 没有提供方和消费方。
- 没有字段类型或必填说明。
- 没有错误处理。
- 修改旧契约但没有兼容策略。
- 状态归属不清。
