# 开发工作流协同编排评分表

状态: draft
版本: v1
适用对象: developer-kit 工作流协同编排记录

## 评分维度

每项 1 到 5 分。

| 维度 | 评分说明 |
| --- | --- |
| 阶段判断 | 是否明确当前阶段和已完成阶段。 |
| 调度理由 | 是否说明为什么选择当前工作流。 |
| 插入判断 | 是否能根据触发信号插入问题定位、契约、安全等工作流。 |
| 回退判断 | 是否能在信息不足时回退到正确工作流。 |
| 跳过理由 | 是否说明为什么可以跳过某些工作流。 |
| 用户确认 | 高风险、冲突或不确定时是否要求确认。 |
| 下一步清晰度 | 是否明确下一步工作流、输入和产出。 |

总分：35 分。

## 总分判断

```text
31-35 分：编排清楚，可以继续推进。
26-30 分：基本可用，需要补充插入、回退或跳过理由。
18-25 分：编排不清，容易失控。
17 分及以下：需要重新调度。
```

## 不合格信号

- 命中一个工作流就结束。
- 不说明为什么跳过关键阶段。
- 发现新风险但不插入检查。
- 信息不足仍继续实现。
- 没有下一步判断。
