# UI 设计师模板

## 当前可用模板

- `ui-brief-template.md`：用于输出 UI brief、页面信息架构、关键组件、交互状态和设计交接说明。
- `design-specification-template.md`：用于确认设计规范、目标端、视觉方向和适配约束。
- `design-tokens-template.json`：平台中立的颜色、字体、间距、状态和组件令牌模板。
- `platform-adaptation-template.md`：用于记录令牌到具体平台、框架和主题系统的映射。
- `design-system-audit-template.md`：用于检查设计系统、品牌规范、组件库和一致性风险。
- `design-input-analysis-template.md`：用于整理设计输入、事实、推断和待确认问题。
- `responsive-adaptation-template.md`：用于整理响应式、多端和 iPad 适配策略。
- `page-type-pattern-template.md`：用于整理页面类型、页面骨架和页面模式复用规则。
- `information-architecture-template.md`：用于整理页面信息优先级和区块。
- `component-library-planning-template.md`：用于整理组件层级、组件清单、变体、状态和适配矩阵。
- `interaction-state-template.md`：用于整理组件状态、反馈和边界。
- `interaction-optimization-template.md`：用于整理交互问题、操作区域、任务路径、反馈恢复和视觉层级优化。
- `accessibility-usability-review-template.md`：用于检查可访问性、可用性、多端可用性和验收标准。
- `design-review-template.md`：用于输出设计评审结论。
- `design-handoff-template.md`：用于输出设计交接说明。
- `design-to-development-handoff-template.md`：用于输出开发实现约束和验收清单。
