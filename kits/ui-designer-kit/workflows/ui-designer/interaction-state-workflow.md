# 交互状态设计工作流

## 目的

围绕页面、组件或流程，补齐用户操作过程中的状态、反馈、异常和边界场景。

## 适用场景

- 页面已有结构，但缺少交互状态。
- 组件涉及加载、错误、空态、权限或禁用。
- 开发需要明确按钮、表单、弹窗、列表、上传下载等状态。
- 测试需要依据 UI 状态设计验收场景。

## 执行步骤

1. 确认用户操作路径。
2. 列出关键组件。
3. 为每个组件补齐默认、悬停、聚焦、加载、成功、失败、禁用、空态等状态。
4. 明确反馈方式和错误提示。
5. 识别权限、数据为空、网络异常、重复提交等边界。
6. 输出状态矩阵和开发交接说明。

## 输出

使用：

```text

```
