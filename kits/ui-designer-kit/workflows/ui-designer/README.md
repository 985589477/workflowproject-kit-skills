# UI 设计师工作流

## 当前可用工作流

- `ui-designer-workflow.md`：UI 设计总入口工作流，用于把产品需求、PRD、页面想法或竞品界面整理成 UI brief、页面结构、组件说明和交互状态说明。
- `design-specification-workflow.md`：设计规范确认，用于明确品牌、视觉、组件、布局、交互和适配规范。
- `design-token-workflow.md`：设计令牌与平台适配，用于输出平台中立令牌，并映射到 CSS、TypeScript、Swift、Kotlin、Dart 或 WXSS 等目标平台。
- `design-system-audit-workflow.md`：设计系统检查，用于判断已有规范、组件库和风格一致性状态。
- `design-input-analysis-workflow.md`：设计输入分析，用于把 PRD、需求或模糊想法整理成可设计输入。
- `responsive-adaptation-workflow.md`：响应式与多端适配，用于处理 Web、移动端、iPad、小程序和不同断点布局。
- `page-type-pattern-workflow.md`：页面类型设计模式，用于判断首页、列表页、详情页、表单页、看板页等页面骨架。
- `information-architecture-workflow.md`：信息架构，用于拆页面信息、优先级和区块。
- `component-library-planning-workflow.md`：组件库规划，用于拆分组件层级、复用边界、变体和状态。
- `interaction-state-workflow.md`：交互状态设计，用于补齐组件状态、反馈和异常。
- `interaction-optimization-workflow.md`：交互体验优化，用于处理操作区域、任务路径、反馈恢复和视觉层级问题。
- `accessibility-usability-review-workflow.md`：可访问性与可用性检查，用于检查任务路径、操作反馈、读屏、键盘、触控和多端可用性。
- `design-review-workflow.md`：设计评审，用于检查 UI 方案是否可交接。
- `design-handoff-workflow.md`：设计交接，用于整理给产品、开发、测试的交接说明。
- `design-to-development-handoff-workflow.md`：设计到开发实现约束，用于明确布局、组件、状态、数据、适配和验收规则。
