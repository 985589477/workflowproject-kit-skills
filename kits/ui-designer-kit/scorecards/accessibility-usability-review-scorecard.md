# 可访问性与可用性检查评分表

适用对象：UI 可用性检查、无障碍检查、设计评审

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 任务可完成 | 20 | 用户是否能理解目标并完成核心任务 |
| 路径效率 | 15 | 是否存在无价值的重复步骤、绕路或中断点 |
| 操作区域 | 20 | 触控热区、点击范围、键盘焦点和误操作风险是否合理 |
| 反馈与恢复 | 15 | 操作结果、错误、空态、重试、取消和恢复是否清楚 |
| 视觉可读 | 15 | 颜色对比、字号、间距、层级和状态区分是否可读 |
| 多端可用 | 15 | 移动端、平板、桌面、横屏和特殊设备是否可用 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可进入交付 |
| 75-89 | 可试用，需要补少量可用性问题 |
| 60-74 | 存在明显使用风险 |
| 0-59 | 不建议交付 |
