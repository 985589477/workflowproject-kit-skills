# 产品经理模板

这里放产品经理角色模板，例如 PRD 生成、用户故事生成、需求分析、路线规划。

## 当前可用模板

- `requirement-analysis-template.md`：需求分析模板，用于把产品想法、需求草稿、会议纪要或用户反馈整理成结构化需求分析。
- `prd-template.md`：PRD 模板，用于把需求分析结果转化为可被设计、开发和测试承接的 PRD 初稿。
- `acceptance-criteria-template.md`：验收标准模板，用于把 PRD、功能说明或功能清单转化为可验证的完成标准。
- `feature-planning-template.md`：功能规划模板，用于把产品目标、PRD 和功能清单整理成可执行的功能范围和优先级。
- `user-story-template.md`：用户故事模板，用于把 PRD、用户场景和功能清单转化为用户视角的故事表达。
- `user-feedback-template.md`：用户反馈整理模板，用于把用户反馈、客服记录或评论整理成问题、痛点和需求机会。
- `competitor-analysis-template.md`：竞品分析模板，用于把竞品资料整理成差异点、可借鉴点、风险和产品机会。
- `priority-decision-template.md`：优先级判断模板，用于在多个需求、功能或产品机会之间做可解释的取舍。
- `version-planning-template.md`：版本规划模板，用于把产品目标、功能规划和优先级判断整理成阶段化版本路线。
- `product-strategy-template.md`：产品策略判断模板，用于判断产品方向、机会点或策略主题是否值得推进。
- `requirement-pool-template.md`：需求池管理模板，用于把多个来源的需求整理成可长期维护的需求台账。
- `product-roadmap-template.md`：产品路线图模板，用于基于策略、需求池、优先级和版本规划生成中长期产品路线图。
- `requirement-change-evaluation-template.md`：需求变更评估模板，用于评估新增需求、范围变化和优先级调整对当前项目的影响。
- `version-retrospective-template.md`：版本复盘模板，用于复盘版本目标达成、需求交付、变更影响、质量问题和后续改进。
