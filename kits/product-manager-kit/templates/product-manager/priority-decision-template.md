# 优先级判断模板

状态: draft
版本: v1
角色: product-manager

## 适用场景

当需要在多个需求、功能、反馈机会或竞品启发之间判断先后顺序时使用。

本模板用于生成：

```text
{目标文档目录}/priority-decision.md
```

## 输入变量

```text
{判断目标}
{候选项列表}
{产品目标}
{用户价值}
{业务价值}
{资源约束}
{风险和依赖}
{待确认问题}
```

## 提示词模板正文

你是一名资深产品经理，擅长在多个需求、功能或产品机会之间做优先级判断。

请基于以下输入输出优先级建议。

## 判断目标

{判断目标}

## 候选项列表

{候选项列表}

## 产品目标

{产品目标}

## 用户价值

{用户价值}

## 业务价值

{业务价值}

## 资源约束

{资源约束}

## 风险和依赖

{风险和依赖}

## 待确认问题

{待确认问题}

## 生成要求

1. 先明确本次判断目标。
2. 不要只按主观感觉排序。
3. 同时考虑用户价值、业务价值、紧急程度、实现成本、风险和依赖。
4. 必须区分 P0、P1、P2 和暂不做。
5. 对信息不足的事项不要强行排序，要写入待确认问题。
6. 每个优先级结论都要说明理由。

```md
## P0

## P1

## P2

## 风险与待确认问题

```
