# 产品路线图模板

状态: draft
版本: v1
角色: product-manager

## 适用场景

当需要基于产品策略、需求池、优先级判断和版本规划生成中长期产品路线图时使用。

本模板用于生成：

```text
{目标文档目录}/product-roadmap.md
```

## 输入变量

```text
{路线图目标}
{时间范围}
{产品策略}
{需求池}
{优先级判断}
{版本规划}
{业务目标}
{资源约束}
{关键节点}
{风险和依赖}
{待确认问题}
```

## 生成要求

1. 先明确路线图服务的产品目标和时间范围。
2. 不能把路线图写成普通功能清单。
3. 每个阶段必须有阶段主题、目标和关键事项。
4. 需要说明阶段之间的演进逻辑。
5. 需要标记不进入路线图的内容和原因。
6. 需要保留依赖、风险、假设和待确认问题。
7. 需要说明后续进入 PRD、版本规划或开发排期的建议。
