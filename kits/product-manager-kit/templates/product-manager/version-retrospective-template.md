# 版本复盘模板

状态: draft
版本: v1
角色: product-manager

## 适用场景

当一个版本完成、上线或阶段结束后，需要复盘目标达成、需求交付、变更影响、质量问题、协作问题和后续改进时使用。

本模板用于生成：

```text
{目标文档目录}/version-retrospective.md
```

## 输入变量

```text
{版本背景}
{版本目标}
{复盘范围}
{版本规划}
{PRD}
{验收标准}
{需求变更记录}
{实际交付结果}
{上线结果}
{用户反馈}
{数据表现}

{未完成事项}
{待确认问题}
```

## 生成要求

1. 先明确版本背景、版本目标和复盘范围。
2. 对比原计划和实际结果。
3. 区分事实、原因分析、判断结论和改进建议。
4. 必须复盘需求交付、需求变更、质量问题、协作问题和用户反馈。
5. 不要把复盘写成泛泛总结。
6. 必须输出后续行动，并说明进入需求池、路线图、版本规划或流程改进的事项。
7. 信息不足时写入待补充材料，不要编造数据。
