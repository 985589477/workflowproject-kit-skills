# 测试输出评分表

适用对象: 测试计划、测试用例、回归范围、发布验收结论

## 评分维度

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 范围清晰度 | 20 | 是否明确测试范围、非范围和测试对象 |
| 验收标准承接 | 20 | 是否承接 PRD、验收标准或开发变更说明 |
| 场景覆盖 | 20 | 是否覆盖核心路径、边界、异常、权限和数据状态 |
| 风险判断 | 15 | 是否识别高风险模块、回归范围和发布风险 |
| 用例可执行性 | 15 | 用例是否有前置条件、步骤和预期结果 |
| 结论可用性 | 10 | 是否能给出明确通过、暂缓、需修复或需确认结论 |

## 结论

| 分数 | 结论 |
| ---: | --- |
| 90-100 | 可执行并可用于发布判断 |
| 75-89 | 可试用，需要补充少量场景 |
| 60-74 | 待补齐，不建议直接执行 |
| 0-59 | 不通过，需要重新整理需求或验收标准 |
