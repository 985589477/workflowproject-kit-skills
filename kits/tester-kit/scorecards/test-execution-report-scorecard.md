# 测试执行报告评分表

适用对象：测试执行报告、阶段测试报告

| 维度 | 分值 | 评分说明 |
| --- | ---: | --- |
| 执行概况 | 20 | 是否说明测试范围、时间、进度和结论 |
| 结果清楚 | 20 | 是否说明通过、失败、阻塞和未执行情况 |
| 缺陷透明 | 20 | 是否说明缺陷等级、状态和阻塞项 |
| 风险完整 | 20 | 是否说明未覆盖范围和残余风险 |
| 发布建议 | 20 | 是否给出可发布、有条件发布或暂缓发布建议 |

## 结论

90-100 可支撑发布决策；75-89 可试用；60-74 需补风险和缺陷；0-59 不足以决策。
