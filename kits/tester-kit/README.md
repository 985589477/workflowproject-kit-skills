# tester-kit

导出时间：2026-10-14

`tester-kit` 是从 WorkflowProject 导出的测试工程师能力包。

它用于把 PRD、验收标准、开发变更、接口文档、缺陷反馈或上线前检查需求整理成验收标准检查、测试策略、测试计划、测试数据与环境准备、测试用例、接口与集成测试、兼容性测试、非功能风险测试、回归范围、探索式测试、自动化测试规划、测试执行报告和发布验收建议。

## 最快使用

```text
请使用 tester-kit 处理我的测试任务：{写下你的任务}
```

```text
START-HERE.md

```
