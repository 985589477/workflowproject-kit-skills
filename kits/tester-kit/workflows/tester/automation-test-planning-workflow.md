# 自动化测试规划工作流

## 目的

用于判断哪些测试适合自动化、优先级如何、自动化收益和维护成本是否合理。

## 什么时候使用

- 功能需要长期回归。
- 重复测试成本高。
- 项目需要建设自动化测试资产。
- 用户要求自动化测试策略。

## 执行步骤

1. 识别稳定、高频、关键、重复的测试场景。
2. 排除变化频繁、依赖复杂、收益低的场景。
3. 按接口、端到端、UI、冒烟、回归分层规划。
4. 明确自动化数据、环境、触发时机和维护责任。
5. 输出自动化测试规划。

## 输出要求

- 自动化候选场景。
- 不适合自动化场景。
- 自动化分层。
- 优先级。
- 数据和环境要求。
- 维护成本和风险。
