# 缺陷复现工作流

## 目的

把用户反馈、报错截图、日志、测试失败或线上问题整理成可复现、可定位、可交给开发处理的缺陷说明。

## 适用场景

- 用户反馈某个功能异常。
- 测试过程中发现 bug。
- 线上出现报错、白屏、接口失败或体验异常。
- 开发需要复现步骤和影响范围。

## 执行步骤

1. 整理缺陷现象。
2. 提取环境、账号、设备、版本和数据条件。
3. 整理复现步骤。
4. 记录实际结果和预期结果。
5. 判断严重程度和影响范围。
6. 标记缺失信息。
7. 输出缺陷复现报告。

## 输出

使用：

```text
06-templates/tester/defect-reproduction-template.md
```

## 质量检查

使用：
