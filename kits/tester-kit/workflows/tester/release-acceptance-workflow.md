# 发布验收工作流

## 目的

在版本发布、上线或交付前，整理测试结果、未解决问题、回归状态和发布风险，形成是否可以发布的验收建议。

## 适用场景

- 功能准备上线。
- 测试执行完成，需要给发布建议。
- 仍有缺陷或未覆盖风险，需要判断是否阻塞。
- 需要交付发布验收结论。

## 执行步骤

1. 汇总测试范围和执行结果。
2. 汇总通过项、失败项、阻塞项和未覆盖项。
3. 判断缺陷严重程度和发布影响。
4. 检查回归范围是否完成。
5. 输出发布建议：可发布、修复后发布、暂缓发布、需要用户确认。
6. 标记上线后观察点。

## 输出

使用：

```text
06-templates/tester/release-acceptance-template.md
```

## 质量检查
